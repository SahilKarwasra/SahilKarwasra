## 👨‍💻 About Me

I'm a software engineer who builds **full products, both halves**: the **Go** services that move messages, media and money in real time, and the **Kotlin Multiplatform** apps that ship from one codebase to Android, iOS and Desktop. I work **AI-first** — pairing with coding agents to move fast, while keeping the architecture hand-crafted.

- 🔭 Recently shipped **Leet** — a group video-calling app with a Go **WebRTC SFU** and a KMP client on Android, iOS & Desktop
- 💳 Building **MoePay** — a GBP e-wallet with a double-entry ledger, idempotent payments and offline-ready chat
- 🤖 Wrote a **Claude Code skill** that teaches AI agents to scaffold multi-module Compose Multiplatform apps
- ⚡ Always exploring new tech to make apps faster and smoother
